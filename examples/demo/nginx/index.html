Features

Everything you need to monitor and manage Docker containers

📊

Real-time Monitoring

Updates every second with CPU, memory, network, and block I/O metrics for all running containers.

💻

Beautiful TUI

Built with bubbletea and lipgloss. Keybindings for start, stop, restart, inline logs, and exec.

🌐

Web Dashboard

Glassmorphism UI with live SVG sparklines, status filters, search highlighting, and 3D hover effects.

📱

Mobile App

Expo / React Native client mirrors the dashboard on your phone with full controls and bilingual support.

🛡️

Token Security

Secured control API with token verification. Guest read-only mode and localStorage session tokens.

🔍

Health Scoring

Dynamic 0-100 health score based on CPU, memory, disk I/O, restarts, and uptime with neon indicators.

📝

Inline Logs

Advanced web modal with keyword search, log level filters, tail control, highlighting, and instant download.

💻

Command Execution

Execute shell commands inside running containers from TUI or web. Quick templates, separated output, copy helper.

📂

Backup Snapshots

Portable zip archives of your container scene. Preview, create, browse, and download with audit trail.

🏠

Web Container Controls

Start, stop, and restart containers directly from the web dashboard with token-gated actions.

🔗

Port Mappings Visualizer

Displays container port mappings and exposed ports as interactive badges and clean tags on dashboard cards.

📐

Color-coded Status

Green for running, red for stopped/exited. High CPU usage highlighted in red for instant visual triage.

📩

One-Click Web Upgrade

Browser-based self-upgrades next to the version badge. Queries GitHub releases, detects install type, and streams progress.

🌊

Theme Toggle

Real-time light and dark theme switching with automatic system color-scheme preference detection.

🌐

Multi-language Support

Interactive web dashboard supports language toggling between English and Chinese via the navigation header.

🚮️

Disk Cleanup (Prune)

Preview and remove unused images and dangling volumes from the dashboard with dry-run and audit logging.

📋

Operation Audit Center

Searchable audit log with filters, pagination, and JSON/Markdown export for start, stop, restart, and exec events.

📁

Container File Transfer

Browse, upload, download, and archive files inside containers from the FILES tab with jail-root confinement.

🤖

Duty Assistant

Plain-language on-call copilot answers ops questions with evidence from live state, logs, and audit events.

⚙️

Layered Configuration

Every setting resolves through CLI flag > env var > config.yaml > built-in default. Sample config generated on first launch.

📐

Color-coded Status

Green for running, red for stopped/exited. High CPU usage highlighted in red for instant visual triage.

💻

Auto-detection

Automatically detects Docker socket paths including standard, Colima, WSL, OrbStack, Podman, and Rancher Desktop.

🗺️

Network Topology

Visualize container network relationships and connections in an interactive topology graph on the dashboard.

Quick Install

Get started in seconds with a single command

Using go install
# Install latest release
go install github.com/zsuroy/dockerview-go/cmd/dockerview@latest
From source
# Clone, build, and run
git clone https://github.com/zsuroy/dockerview-go.git
cd dockerview-go && make build
./build/dockerview
Enable web dashboard
# Start with HTTP server on port 8080
dockerview -server

# Open in browser
open http://localhost:8080
